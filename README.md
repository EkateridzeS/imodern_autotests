# UI-автотесты iModern

Учебный проект по автоматизации функционального тестирования интернет-магазина [iModern](https://imodern.ru/).

## Используемые технологии

- Python
- Playwright
- Pytest
- Allure Report
- Page Object Model
- Python-dotenv

## Структура проекта

- `autotest/` — автоматизированные тесты.
- `core/` — конфигурация, логирование, маскирование данных и создание скриншотов.
- `ui/` — классы страниц, локаторы элементов и методы взаимодействия с ними.
- `data/cases.json` — тестовые данные.
- `conftest.py` — фикстуры и обработка результатов тестирования.
- `requirements.txt` — зависимости проекта.
- `.env.example` — шаблон конфигурации.

## Запуск проекта

Установка зависимостей:
```bash
python3 -m pip install -r requirements.txt
python3 -m playwright install chromium
```
Создание файла конфигурации:
```bash
cp .env.example .env
```

В файле `.env` необходимо указать данные тестового аккаунта.

Запуск всех автотестов:
```bash
python3 -m pytest -v -s --clean-alluredir
```

Открытие отчёта Allure:
```bash
allure serve allure-results
```

Для запуска тестов в режиме видимого браузера необходимо установить `HEADLESS=false` в файле `.env`.

## Логирование и безопасность

- Поддерживаются уровни логирования DEBUG, INFO, WARNING и ERROR.
- Логи сохраняются в файле `logs/run.log`.
- Конфиденциальные значения в сообщениях логгера заменяются на `[REDACTED]`.
- Реализовано автоматическое прикрепление скриншотов к отчёту Allure с маскированием данных.
- Для каждого теста создаётся отдельный контекст браузера.
- Учётные данные, логи и локальные отчёты исключены из Git.

## Ограничения

Сквозной сценарий выполняется до финального подтверждения заказа. Создание реального заказа отключено, поэтому тест получает статус SKIPPED. Финальное создание заказа и получение его номера на реальном сайте не проверены.

Перед публикацией результатов необходимо проверять отсутствие персональных данных. При обнаружении CAPTCHA тестирование прекращается.
